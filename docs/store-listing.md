## 商品详情（Store listing）

### 摘要

不用填：后台直接取 manifest 的 `description`（`wxt.config.ts`，最多 132 个字符）：

> 在 arXiv HTML 页面上划线、高亮、做笔记，支持沉浸式翻译 / 陪读蛙的译文。

### 说明（Description）

```text
在 arXiv 论文的 HTML 页面上划线、高亮、写笔记。原文可以划，沉浸式翻译、陪读蛙显示的译文也可以划；笔记随论文保存，换台电脑也在。

■ 划线与笔记
· 选中文字弹出工具栏：五种颜色一键高亮，或高亮后直接写笔记
· 点击已有的高亮可以改颜色、编辑笔记、删除
· 高亮不修改页面结构，翻译插件重新渲染页面时也不会丢

■ 原文和译文都能划
· 支持沉浸式翻译、陪读蛙的双语对照译文
· 译文存档：翻译插件显示过的译文按段落存档。下次打开时不开翻译插件也能看到，措辞不会变，译文上的笔记也不会漂移

■ 侧边栏
· 点击工具栏里的扩展图标打开侧边栏，按文档顺序列出本篇的所有笔记，点击跳转到原文位置
· 整篇笔记可以复制为 Markdown

■ 论文库
· 浏览过的论文自动收进论文库，标题、作者、年份从 arXiv 获取
· 分组（类似标签）、标记、多种排序；可按标题、作者、论文 id、划线和笔记内容搜索
· 导出 / 导入备份文件，用于换电脑或定期备份

■ 云同步
· 通过 WebDAV（坚果云、Nextcloud、群晖等）在多台电脑之间同步笔记、论文库、分组和译文存档

■ 导入 PDF
· 没有 HTML 版本的论文，可以用 MinerU 把 PDF 解析成和 arXiv HTML 相同结构的页面，同样可以划线、写笔记、用翻译插件翻译
· 需要自备 MinerU Token，并在扩展详情页打开"允许访问文件网址"。PDF 会上传到 MinerU 的服务器解析

■ 隐私
扩展没有自己的服务器，不收集、不统计任何数据。笔记默认只保存在本机；开启云同步后只写到你自己的 WebDAV 服务器。详见隐私政策。

适用页面：arxiv.org/html/…、ar5iv.org/html/…（论文摘要页 arxiv.org/abs/… 上请点 "HTML" 链接进入）。

开源（MIT）：https://github.com/Clamours/arxiv-html-helper

————————

Highlight and take notes on arXiv HTML papers — on the original text and on translations shown by Immersive Translate or Read Frog.

· Highlight in five colors and attach notes; click a highlight to recolor, edit or delete it
· Highlights never modify the page, so they survive when translation extensions re-render it
· Saved translations: translated paragraphs are kept, so notes on them never drift
· Side panel with all notes of the paper in document order; copy them as Markdown
· Paper library with groups, stars, sorting and full-text search; backup export / import
· Sync across computers via WebDAV
· Import PDFs (parsed by MinerU) as arXiv-style pages you can annotate

No server, no tracking. Notes stay in your browser unless you turn on sync to your own WebDAV server.
Open source (MIT): https://github.com/Clamours/arxiv-html-helper
```

如果以后打包时启用了 Google Drive 同步（填了 `GOOGLE_CLIENT_ID`），把"云同步"一节改成"通过 WebDAV（坚果云、Nextcloud、群晖等）或 Google Drive……"，英文部分同理。

## 隐私权规范（Privacy practices）

### 单一用途（Single purpose）

```text
Highlight and take notes on arXiv HTML paper pages. All features serve this purpose: highlighting and notes on the paper text (including translations inserted by translation extensions), a side panel and library to review and organize the notes, optional sync / backup of the notes across the user's computers, and optional conversion of PDFs into the same kind of paper page so they can be annotated too.
```

### 权限理由（Permission justification）

后台会为 manifest 里的每项权限各给一个输入框。下面的 `identity` 只在启用 Google Drive 同步打包时才会出现。

**storage**

```text
Stores the user's highlights, notes, paper library (titles, authors, groups, stars) and settings locally in chrome.storage.local. Nothing is sent to any developer server; there is none.
```

**unlimitedStorage**

```text
Users accumulate notes on many papers over time, and the extension stores saved translations and full paper pages generated by the optional "Import PDF" feature (single-file HTML with embedded images, often several MB each) in IndexedDB. The default quota would be exceeded and data lost.
```

**sidePanel**

```text
The main UI: clicking the toolbar icon opens a side panel listing all highlights and notes of the current paper in document order, with jump-to-location, Markdown export and the paper's groups.
```

**alarms**

```text
Schedules periodic background sync when the user has turned on cloud sync (to their own WebDAV server or Google Drive), so notes stay in sync across the user's computers.
```

**downloads**（可选权限）

```text
Optional, requested only when the user uses "Import PDF". Translation extensions cannot run on chrome-extension:// pages but do run on local files, so the generated paper page is saved to the Downloads folder (Downloads/arxiv-html-helper/) via chrome.downloads and opened from there. Files are removed again when the user removes the paper from the library.
```

**identity**（只在启用 Google Drive 同步时）

```text
Used only for optional Google Drive sync: chrome.identity.getAuthToken obtains an OAuth token for the drive.appdata scope, so notes are synced to the hidden app-data folder in the user's own Google Drive. The extension cannot access any other files.
```

**主机权限（Host permission）**

```text
- https://export.arxiv.org/*: the paper library fetches titles, authors and years of papers the user has opened from the official arXiv API (only arXiv ids are sent).
- Content scripts on arxiv.org/html/*, ar5iv.org/html/* and ar5iv.labs.arxiv.org/html/*: render highlights and the note toolbar on arXiv HTML paper pages, which is the extension's single purpose.
- Content script on file:///*: papers imported from PDF are opened as local HTML files. The script only activates on pages that contain the extension's <meta name="ahh-paper-id"> marker and does nothing on any other local file. This also requires the user to turn on "Allow access to file URLs" themselves.
- Optional https://*/* and http://*/*: NOT granted at install. They are requested at runtime via chrome.permissions.request, limited to the specific origins needed, only when the user turns on a feature that needs it: the WebDAV server URL the user typed in (any host, possibly self-hosted or on a LAN over http), the Google Drive API, or the MinerU API, upload and result CDN hosts for "Import PDF". The exact hosts cannot be known in advance, which is why they are declared as optional wildcards.
```

### 远程代码（Remote code）

选 **否，我没有使用远程代码**（No, I am not using remote code）。所有脚本、pdf.js 及其 wasm 解码器都打包在扩展里；MinerU 返回的是 Markdown 和图片数据，不是代码。

### 数据使用（Data usage）

后台问的是"收集"哪些用户数据。数据只在本机处理时不算收集，但同步和导入 PDF 会把数据发到用户选择的服务，所以从宽勾选：

| 类别 | 勾选 | 原因 |
|---|---|---|
| 个人身份信息（Personally identifiable information） | 否 | |
| 健康信息（Health information） | 否 | |
| 财务和付款信息（Financial and payment information） | 否 | |
| 身份验证信息（Authentication information） | **是** | WebDAV 用户名和密码、MinerU Token：保存在本机，只发给对应服务用于登录 |
| 个人通讯（Personal communications） | 否 | |
| 位置（Location） | 否 | |
| 网络记录（Web history） | **是** | 论文库记录用户打开过的 arXiv 论文，开启同步时同步到用户自己的存储；论文 id 发给 arXiv API 获取标题 |
| 用户活动（User activity） | 否 | 不监听点击、按键、滚动等 |
| 网站内容（Website content） | **是** | 划线的引文、笔记、译文存档；导入 PDF 时 PDF 会上传到 MinerU |

三项承诺全部勾选：

- 我不会出于已获批准的用途之外的用途向第三方出售或传输用户数据
- 我不会为实现与我的产品的单一用途无关的目的而使用或转移用户数据
- 我不会为确定信用度或实现贷款而使用或转移用户数据

## 测试说明（Test instructions）

用户名、密码留空。附加说明：

```text
No account is needed for the core features.
1. Open https://arxiv.org/html/1706.03762v7
2. Select any text: a toolbar appears. Click a color to highlight, or "笔记" (Note) to highlight and write a note.
3. Click the extension's toolbar icon to open the side panel listing all notes; click one to jump to it.
4. In the side panel, the top-right "论文库" (Library) link opens the paper library.
Cloud sync (WebDAV) and "Import PDF" (needs a MinerU token) are optional and need the user's own accounts; the optional host permissions are only requested when those features are turned on.
The UI is in Chinese.
```
