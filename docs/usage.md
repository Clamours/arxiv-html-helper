# 使用说明

扩展在 `arxiv.org/html/…`、`ar5iv.org/html/…` 的论文页面上工作。在论文摘要页（`arxiv.org/abs/…`）上，点 "HTML" 链接进入 HTML 版本；没有 HTML 版本的论文可以[导入 PDF](import.md)。

## 划线与笔记

- 选中文字后会弹出工具栏：点颜色直接高亮，点铅笔图标高亮并打开笔记编辑框
- 点击已有的高亮可以改颜色、写笔记、删除
- 原文和沉浸式翻译 / 陪读蛙显示的译文都可以划。翻译插件显示过的译文会按段落自动存档：之后打开这篇论文时，有存档的段落始终显示存档的译文，不开翻译插件、换一台电脑、插件重新翻译出不同措辞时都不变，译文上的笔记也就不会漂移。详见[译文存档](saved-translations.md)

## 侧边栏

- 点浏览器工具栏里的扩展图标打开侧边栏。侧边栏只在当前标签页打开，切到其他标签页时不显示
- 按原文顺序列出本篇的所有笔记，点击一条跳到原文位置。鼠标移到笔记上可以编辑、删除；原文位置找不到的笔记会标出来，仍然显示引文
- 右上角可以标记这篇论文、把整篇笔记复制为 Markdown、打开论文库
- 标题下方是论文所在的分组（可以加入 / 移出）和评分，以及检测到的译文段落数（用来判断对翻译插件的适配是否生效）
- 有译文存档时，可以隐藏存档（只影响本机），或清除本篇的存档（清除后会重新存档当前显示的译文）

## 论文库

侧边栏右上角的"论文库"会打开一个新标签页，列出所有浏览过的论文，标题、作者、年份从 arXiv API 自动获取。

- 可以按最近笔记、最近打开、最近加入、评分、划线数、标题排序；搜索框可以搜标题、作者、arXiv 编号、划线和笔记内容，快捷键是 `/`
- 鼠标移到论文上，可以标记、把笔记复制为 Markdown、从论文库移除
- **分组**：一篇论文可以属于多个分组（相当于标签）。浏览过的论文自动加入论文库，默认不属于任何分组。左侧栏按 全部 / 已标记 / 未分组 / 各分组 筛选；分组可以新建、重命名、改颜色、删除，或把整个分组的笔记复制为 Markdown
- **评分**：每篇论文可以评 1–5 星。在论文库每行右侧（未评分时鼠标移上去才出现）或侧边栏的分组行右侧点星，再点当前星级可以清除

## 同步与备份

- **云同步**：论文库右上角的"云同步"可以通过 WebDAV（坚果云等）或 Google Drive 在多台电脑之间自动同步笔记、论文库、分组、译文存档和导入论文的页面，删除也会同步。设置方法和合并规则见[云同步](sync.md)
- **备份**：论文库右上角的"⋯"菜单里可以导出、导入备份。导出为一个 JSON 文件，包含全部论文、划线、笔记、分组、标记和评分（含译文上的笔记）；导入时先预览，笔记按 id 合并、保留修改时间较新的一份，论文的分组取两边的并集，只增不删。可以用来换电脑迁移，或者定期备份

## 导入 PDF

论文库右上角的"导入 PDF"用 MinerU 解析 PDF，生成和 arXiv HTML 结构相同的论文页面，同样可以划线、写笔记、用翻译插件翻译，左侧有和 arXiv 一样的目录。页面在项目主页的阅读页里打开，翻译插件和 ChatGPT 侧边栏都能读到正文；用 ChatGPT 提问前，要先在页面上选中一点文字。需要 MinerU Token，详见[导入 PDF](import.md)。
