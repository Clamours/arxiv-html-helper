一个 Chrome 扩展。在 arXiv 的 HTML 论文页上高亮和批注，原文和沉浸式翻译、陪读蛙显示的译文都能划；笔记随论文保存，换台电脑也在。

3.2.1 Scaled Dot-Product Attention

The input consists of queries and keys of dimension dk, and values of dimension dv. We compute the dot products of the query with all keys, divide each by √dk, and apply a softmax function to obtain the weights on the values.

输入由维度为 dk 的查询和键、维度为 dv 的值组成。我们计算查询与所有键的点积，将每个点积除以 √dk，再用 softmax 得到值的权重。

笔记
divide each by √dk 缩放是为了防止 dk 较大时点积过大，把 softmax 推进梯度很小的区域。

功能

为读 arXiv HTML 论文设计，和翻译插件一起用也不会乱。

划线与笔记

选中文字弹出工具栏，五种颜色一键高亮，或高亮后直接写笔记。点击已有的高亮可以改色、编辑、删除。

原文和译文都能划

支持沉浸式翻译、陪读蛙的双语对照。高亮不修改页面结构，翻译插件重新渲染时也不会丢。

译文存档

翻译插件显示过的译文按段落存档。下次打开时不开翻译插件也能看到，措辞不会变，译文上的笔记也不会漂移。

侧边栏与导出

侧边栏按文档顺序列出所有笔记，点击跳转到原文位置；整篇笔记可以复制为 Markdown。

论文库与分组

浏览过的论文自动收进论文库，标题和作者从 arXiv 获取。支持分组、标记、排序，以及按标题、作者、笔记内容搜索。

同步、备份、导入 PDF

通过 WebDAV（坚果云等）或 Google Drive 在多台电脑间同步；可导出 / 导入备份。没有 HTML 版的论文可以用 MinerU 把 PDF 转成同样的页面。

你的笔记只属于你

扩展没有自己的服务器，不收集、不统计、不上传任何数据。

默认只存在本机

笔记、论文库、分组和译文存档都保存在浏览器本地。

同步去向由你决定

开启云同步后，数据只写到你自己的 WebDAV 服务器或 Google Drive 的应用专用文件夹。

用到第三方时会说明

论文库向 arXiv API 查询标题和作者；导入 PDF 时文件会上传到 MinerU 解析。

安装

Chrome 应用商店版即将上架。现在可以从源码构建：

  1. 下载源代码：git clone https://github.com/Clamours/arxiv-html-helper.git
  2. 安装依赖并构建：npm install，然后 npm run build
  3. 打开 chrome://extensions，开启右上角的"开发者模式"
  4. 点"加载已解压的扩展程序"，选择项目里的 .output/chrome-mv3 文件夹
  5. 打开任意一篇 arXiv HTML 论文（如 arxiv.org/html/1706.03762v7），选中文字即可开始划线
