# 译文存档

沉浸式翻译、陪读蛙的译文是每次打开页面时现翻的：换一台电脑、没开翻译插件、换了翻译服务或模型，译文都可能不一样。译文层笔记原本只能靠模糊匹配跟着译文走，变化太大就会定位不到。

译文存档把翻译插件显示过的译文保存下来，之后由扩展自己显示。

## 行为

- **自动存档全部段落**：页面上出现的译文，连续 2 秒没有变化（AI 翻译是流式输出的）、也没有加载动画时，按段落存档。不需要划线
- **存档优先**：已有存档的段落不再覆盖。打开论文时，有存档的段落显示存档的译文，同一段里翻译插件的译文被隐藏；两者一字不差时照常显示翻译插件的译文（保留插件的样式）。已经显示着存档的段落不再改回插件的译文：陪读蛙会把段落里的存档也当作原文重翻，来回切换会让页面不停闪烁
- **不开翻译插件也显示**：存档的译文始终显示。想只看原文，在侧边栏点"隐藏"（只影响本机）
- **论文改版**：每段存档都记录了当时原文的哈希。原文变了的段落不再套用旧译文，会重新存档
- **仅译文模式**：翻译插件直接把原文改写成了译文，扩展没法隐藏它，这些段落不显示存档，译文层笔记照旧靠模糊匹配定位。存档仍然会采集
- **更新存档**：换了更好的翻译后想用新译文，在侧边栏点"清除"（点两次确认）。清除后，页面上翻译插件当前显示的译文会重新存档。已有的译文层笔记会按新译文模糊匹配
- **从论文库移除论文**时，这篇论文的存档一并作废

## 存储与同步

- 本机存在扩展的 IndexedDB（`ahh-translations`），不在 `chrome.storage.local` 里，也**不进备份文件**（备份只含笔记、论文库和分组）
- 云同步时每篇论文一个文件 `arxiv-notes-tr-<论文 id>.json`，另有索引 `arxiv-notes-translations.json` 记录每篇的指纹；同步时只下载指纹和本机不同的论文。和主同步文件放在同一个位置
- 合并规则：同一段（原文块 + 原文哈希）两台电脑各存了一份时，先存的一份胜出；清除时间之前存的作废

## 安全

存档的 HTML 会插回页面，而且可能来自云端，所以采集和显示时都会清洗：只保留行内格式标签（`b`、`i`、`sub`、`a` 等）和 MathML，属性只保留 `ltx_` 开头的类名、MathML 的排版属性和 `http(s):`/`#` 链接；脚本、图片、事件、样式一律去掉。解析用 `<template>`，过程中不会执行脚本或加载资源。

## 实现

- 数据模型、合并、清洗：`src/core/translations.ts`
- 页面上的采集和显示：`src/content/translations.ts`；存档的 wrapper 由 `src/adapters/index.ts` 里的 `savedTranslation` 适配器识别（`preferred`：同一段有它时只用它）
- 本机存储和 background 里的读写服务：`src/translations/`
- 云同步：`src/sync/translations.ts`
